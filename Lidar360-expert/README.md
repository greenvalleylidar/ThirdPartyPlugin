# WorkBuddy 360expert 1.1.0

“小土”是 LiDAR360 激光雷达点云处理专家，覆盖点云分类、地形建模、林业单木分割，提供操作流程、参数设置与排坑指导。

## 环境与更新

- 使用 Windows，WorkBuddy 需具备并获准使用本地命令执行能力。
- 启动 LiDAR360 并开启其 MCP 服务。
- CLI 位于 `skills/lidar360/scripts/mcp-tool.exe`，按专家包实际安装位置定位。
- 通过 WorkBuddy 支持的专家包更新流程加载 1.1.0，更新后开启新会话并选择“小土”。源码覆盖不会自动刷新已安装副本。
- 本版不再通过旧 `.mcp.json` 自动注册固定地址的连接；服务地址由 CLI 探测，LiDAR360 后端的 MCP 服务保持开启。

## 调用流程

1. 使用包内 `mcp-tool.exe detect_mcp` 探测服务。
2. 将实际返回地址显式传给后续每条命令的 `-url`。
3. 查询目标工具实时 schema，按其定义构造 JSON 参数，再用 `call_tool` 串行执行。
4. 检查进程退出码、MCP 错误标志和业务返回，缺少成功证据时不得报告成功。

详细语法见 `skills/lidar360/references/profiles/mcp_tool_usage.md`。不要使用固定的开发机器路径或默认服务地址。含中文、空格和 JSON 引号的参数应先通过只读数据信息查询验证；文档示例不是可直接执行的参数依据。

## 验证范围与已知问题

交付目录附文件检查及 CLI 只读验证记录；WorkBuddy 安装后真实对话、专家加载和跨机器行为仍待验证。更新后可先询问当前图层信息，再测试 P1 的工具推荐题。
